# Installation Instructions - Enhanced Features

## Quick Install

Run these commands to install the new dependencies:

```bash
# Backend dependencies
cd backend
pip install passlib[bcrypt]==1.7.4 pyjwt==2.8.0

# Restart backend
python -m app.main
```

The frontend will automatically reload with new features!
